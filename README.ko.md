# 짤방 메이커

[English](README.md)

짤방 메이커는 PC에 저장된 영상에서 구간을 고르고 화면을 잘라 움직이는 WebP·GIF·APNG 또는 한 장의 PNG로 저장합니다. 출력 크기를 바꾸거나 영상에 시각을 표시할 수 있습니다. 영상은 PC에서 처리하며, 출력 파일에는 소리가 들어가지 않습니다.

## Windows 11 x64에 설치

[GitHub 릴리스](https://github.com/yunhyok/jjal-maker/releases/latest)에서 `JjalMaker-0.1.0-win-x64-setup.exe`를 받으세요. 설치 언어는 한국어와 영어 중 선택할 수 있습니다. 현재 Windows 계정에 설치되며 관리자 권한이 필요 없습니다. 설치 파일에 Python, Qt, FFmpeg, FFprobe가 포함되어 있어 설치 후에는 오프라인으로 사용할 수 있습니다.

업데이트하려면 새 설치 파일을 실행하세요. 제거하려면 **설정 → 앱 → 설치된 앱**에서 **Jjal Maker**를 선택하세요. 내보낸 이미지와 사용자 설정은 유지됩니다. 설치 파일의 SHA-256은 같은 릴리스의 `SHA256SUMS`에서 확인할 수 있습니다.

## 편집하고 내보내기

1. 영상 파일을 열거나 창에 끌어다 놓습니다. 타임라인의 **시작**과 **끝** 손잡이를 옮기거나 현재 재생 위치를 구간의 시작점 또는 끝점으로 지정합니다.
2. **편집** 화면에서 자를 영역을 드래그하고, 출력 크기와 프레임 속도를 정합니다. **결과** 미리보기는 내보내기와 같은 FFmpeg 필터를 적용합니다.
3. 시각을 표시하려면 **시작점의 시각**을 `HH:MM:SS[.mmm]` 또는 `YYYY-MM-DD HH:MM:SS[.mmm]`으로 입력합니다. 이 값부터 선택 구간의 경과 시간이 더해집니다. 자정을 넘기면 날짜를 입력한 경우 다음 날로 넘어가고, 시각만 입력한 경우 `00:00:00`부터 이어집니다. 위치는 영상 위와 하단 띠 중 고를 수 있습니다.
4. 애니메이션은 **WebP**, **GIF**, **APNG**로 저장할 수 있습니다. 현재 재생 위치의 프레임 한 장은 **PNG**로 저장합니다. **내보내기**를 눌러 저장 위치를 정합니다.

**목표 용량**을 설정하면 인코딩한 파일의 실제 크기를 확인합니다. 필요하면 형식에 따라 화질이나 GIF 팔레트 색상 수를 먼저 낮춘 다음 해상도와 프레임 속도를 줄여, 최대 12회 인코딩합니다. 끝까지 한도를 맞추지 못하면 가장 작았던 시도의 용량을 표시하고 지정한 경로에 결과를 쓰지 않습니다. 성공한 경우 결과 요약에서 실제 용량과 사용한 설정을 확인할 수 있습니다.

## 색상과 입력 형식

내장 FFmpeg에는 H.264, HEVC, APV 디코더가 있습니다. 파일을 열 수 있는지는 컨테이너, 영상 프로파일, 메타데이터에도 좌우됩니다. 이 릴리스에서 Galaxy 실촬영 파일은 검증하지 않았습니다.

**원본 색상**의 **자동**은 PQ 또는 HLG로 표시된 HDR 영상을 SDR로 톤 매핑합니다. **SDR**을 고르면 톤 매핑을 건너뜁니다. 메타데이터가 없거나 잘못된 HDR 영상은 **HDR (PQ)**나 **HDR (HLG)**로 전달 함수를 직접 지정할 수 있습니다. Log 영상에는 카메라 모델과 촬영 프로파일에 맞는 `.cube` LUT를 직접 불러오세요. 톤 매핑과 LUT를 함께 쓰면 톤 매핑을 먼저 적용합니다. 실촬영 Log 영상의 색 정확도는 검증하지 않았습니다. 저장하기 전에 **결과** 미리보기에서 색을 확인할 수 있습니다.

## 빌드와 라이선스

검증 결과는 [v0.1.0 검증 기록](docs/validation.md)에 정리했습니다. GIF는 최대 50 FPS이며 프레임 시간이 10ms 단위로 반올림됩니다. 아주 짧은 WebP는 애니메이션을 유지하기 위해 최소 두 개의 1ms 프레임을 사용합니다. MPEG-TS는 정확한 탐색을 위해 앞부분부터 디코딩하므로 긴 파일의 뒤쪽을 탐색할 때 느릴 수 있습니다. 영상 트랙 길이가 없는 일부 MKV는 컨테이너 길이를 대신 사용하므로 마지막 구간 확인이 필요합니다.
